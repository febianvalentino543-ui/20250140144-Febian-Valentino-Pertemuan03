## Bukti Web Berjalan

Website **AI Asisten untuk UMKM** telah berhasil dijalankan dan diuji pada perangkat desktop dan mobile. Pengujian ini dilakukan untuk memastikan website dapat menampilkan informasi dan fitur dengan baik pada ukuran layar yang berbeda.

### 1. Tampilan pada Desktop

Website berhasil dijalankan pada browser desktop dengan tampilan yang menyesuaikan ukuran layar.

Pada tampilan desktop, pengguna dapat melihat:
- Judul dan deskripsi platform.
- Navigasi menuju bagian **Profil Platform** dan **Pendaftaran Usaha**.
- Informasi mengenai AI Asisten untuk UMKM.
- Logo atau identitas platform.
- Penjelasan mengenai tujuan dan manfaat platform.
- Tampilan konten yang tersusun dengan rapi dan mudah dibaca.

### 2. Tampilan pada Mobile

Website juga telah diuji pada ukuran layar mobile. Tampilan website menyesuaikan ukuran layar sehingga pengguna tetap dapat membaca informasi dan menggunakan navigasi dengan nyaman.

Pada tampilan mobile:
- Konten menyesuaikan lebar layar perangkat.
- Teks tetap dapat dibaca dengan jelas.
- Elemen halaman tersusun secara vertikal.
- Navigasi tetap dapat digunakan.
- Gambar dan komponen website menyesuaikan ukuran layar.
- Tidak terdapat kebutuhan untuk menggunakan tampilan desktop secara khusus.

## 3. Responsive Web Design

Website **AI Asisten untuk UMKM** menerapkan konsep **responsive web design**, yaitu desain website yang dapat menyesuaikan tampilan berdasarkan ukuran layar perangkat yang digunakan.

Responsive design diterapkan agar website dapat memberikan pengalaman penggunaan yang baik pada:
- Desktop
- Laptop
- Tablet
- Smartphone

Dengan adanya responsive design, struktur dan ukuran elemen pada website dapat menyesuaikan ruang layar yang tersedia.


## 4. Kesimpulan Pengujian

Berdasarkan hasil pengujian, website **AI Asisten untuk UMKM** berhasil dijalankan pada perangkat desktop maupun mobile.

Pengujian menunjukkan bahwa:
1. Website dapat dibuka dan dijalankan melalui browser.
2. Tampilan desktop dapat menampilkan konten dengan baik.
3. Tampilan mobile dapat menyesuaikan ukuran layar smartphone.
4. Struktur halaman tetap dapat digunakan pada ukuran layar yang berbeda.
5. Informasi mengenai platform tetap mudah dibaca pada desktop maupun mobile.
6. Website menerapkan konsep responsive web design.

Dengan demikian, website **AI Asisten untuk UMKM** sudah dapat digunakan sebagai prototype platform digital yang membantu UMKM dalam proses digitalisasi usaha melalui bantuan teknologi AI.
